# luna-media

Temporary media host for the Instagram account @lunafortuna.shop.

Instagram's publishing API needs a public URL for every image. Files appear here only for the few minutes it takes to publish an item the owner has approved, and are deleted right after. Nothing in this repository is a website, a product catalogue or a place to browse. Do not rely on any file still being here.

No personal data, no customer content and no access tokens are ever stored in this repository.
